## Outcome

**Winner: Candidate C — Push-Your-Luck Sampling ("The Sample Bag")**  
Score: 27/30

The player draws sample tokens from a bag one at a time. Each draw costs budget (coins + clock) and narrows a live CI band. Core decision: draw again vs. commit conclusion now. Bust = budget exhausted before commit = turn forfeited.

This is the only candidate where statistics **are** the mechanic, not a label on the mechanic. The draw/commit choice is a stopping-rule problem under resource constraints — structurally impossible to hollow into cosmetics.
