## Additional spec elements produced this pass (not in pass 11)

**Risk-flag mitigation:** Cap coin payout on low-variance dice — dominant strategy must require hard-topic faces, not easy-topic grinding. Gate face *unlocks* behind mastery, not coins.

**Progression spine detail:**
- Sessions 1–3: d6, descriptive topics only
- Sessions 4–8: unlock inferential faces (z, t, CI)
- Sessions 9–14: relational faces (correlation, regression, chi-square); d8 unlocks
- Sessions 15–20: ANOVA, effect sizes; d10 + "cursed faces" (high reward, high bust risk)

**Persistent meta:** Die gallery — every saved die configuration = player's statistical autobiography.

**Failure mode:** Wrong answer → "shaky face" (scaffolded re-roll). Face cannot be upgraded until de-shaken. Player sees one-screen Hebrew "why" explanation. Recoverable; diagnostic; cannot be paper-over by avoiding a face (random roll forces confrontation).

**Minimal React prototype (from this pass):**
Zustand store: `Die = Face[6]`, each `{ topic, weight, mastery, shaky }`. Flat 2D hex grid (Tailwind + SVG, no R3F). Weighted random sampler. Forge bottom-sheet every 3 rolls. That's the MVP.
