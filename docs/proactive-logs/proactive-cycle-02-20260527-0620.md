## Gameplay Loop Implemented

**Turn structure:**
1. **Intro screen** — explains mechanic, shows jar composition, color legend
2. **Drawing phase** — tap "שלוף שבב" to draw one chip; running mean + CI update live; tap "עצור וענה" when confident (min 2 draws)
3. **Bust phase** — if CI width > 4.5 after draw: bust animation, explanation of WHY (CI too wide), 0 shekels
4. **Result phase** — success/fail card, shekels earned, CLT explanation, "לחנות" button
5. **Shop phase (bottom sheet)** — buy add/remove/swap chips to reshape distribution for next round

**Statistical concepts in use (not memorized):**
- Mean: displayed live, player watches it stabilize
- Variance/SE: CI width tells player if they have enough draws
- CLT: result screen explains convergence with n
- Stopping rules: the stop-or-continue decision IS the game
