## Design rules (from the real app)

- **RTL first**: `<html lang="he" dir="rtl">`. Math/formulas are forced LTR via the KaTeX isolation rules in `app-classes.css`; mono/latin chips get `direction:ltr`.
- **Primary CTAs are SOLID** — navy `#122460` on light, teal `#4ECDC4` on dark (`--sh-btn-color`), with the `.ws-cta-btn` specular sheen. Glass (`.ws-glass-btn`) is for secondary actions and 3D-world overlays only.
- **Glassmorphism** comes from `.ws-glass-card` over `--sh-page-bg`. Don't hand-roll new glass recipes; use the class.
- **Dark mode** = `html.dark`. All `--sh-*`/`--mm-*` vars flip automatically; components written against the vars need no changes.
- **Fonts**: Heebo (body), Rubik (UI/headings), Assistant, Inter (latin), Playpen Sans Hebrew — loaded by `tokens/fonts.css`. `--ws-hand` is currently parked on Assistant (see the comment in `tokens/app.css`).
- **Spacing/radii**: the app uses raw values (cards typically 16–24px padding, radii 12–20px, pills 999px). Match the nearby real component rather than inventing a scale.

## Known app quirks (mirrored faithfully — do not fix here)

- `--sh-gold` / `--sh-cream` are referenced by `src/components/economy/*` and `RiskBoard.tsx` but **defined nowhere**. RiskBoard uses `var(--sh-gold, #D4A017)`; the economy components inherit fallback colors. Fix belongs in the app repo, not this bundle.

## Regenerating

This bundle is generated by `design-system/scripts/` in the app repo:

```
node design-system/scripts/extract-master.mjs   # tokens + classes (verbatim, self-verifying)
node design-system/scripts/emit-tailwind.mjs    # preflight
node design-system/scripts/subset-css.mjs       # utility subset (after npm run build)
node design-system/scripts/build-ds-bundle.mjs  # _ds_bundle.js
node design-system/scripts/gen-manifest.mjs     # _ds_manifest.json + _adherence.oxlintrc.json
node design-system/scripts/render-check.mjs     # every card must render (bad=0)
```
